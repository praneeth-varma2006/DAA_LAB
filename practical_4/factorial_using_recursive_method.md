# Factorial Using the Recursive Method

## Conclusion

The program recursively multiplies the input by the factorial of the preceding integer, with 0 and 1 as base cases. It reports that factorial is undefined for negative input.

## Complexity

- **Time:** `O(n)` for nonnegative input.
- **Auxiliary space:** `O(n)` for the recursion stack.
