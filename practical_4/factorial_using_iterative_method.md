# Factorial Using the Iterative Method

## Conclusion

The program multiplies the integers from 1 through the input value to calculate its factorial. It reports that factorial is undefined for negative input; `0!` is `1`.

## Complexity

- **Time:** `O(n)` for nonnegative input.
- **Auxiliary space:** `O(1)`.
