# Making Change Using Dynamic Programming

## Conclusion

The program finds the minimum number of supplied coin denominations needed to make the requested amount. It reports when the amount cannot be formed.

## Complexity

- **Time:** `O(A * C)`, where `A` is the amount and `C` is the number of denominations.
- **Auxiliary space:** `O(A)` for the dynamic-programming array.
